# تنسيق العمل

## المسؤوليات المبدئية

سيف: المصدر المعتمد وإضافات الطلب وواجهات العميل والمنيو وتكامل الطلبات.

إبراهيم: إعداد التجربة المستقلة والتشغيل والنسخ الاحتياطي واختبارات القبول وتوثيق الأجهزة.

يُراجع هذا التقسيم مع الطرفين قبل بدء التنفيذ. إعداد هذا المستودع لا يعني اكتمال أي ميزة.

## قواعد التعاون

- `main` للنسخة المراجعة. استخدموا فروع المهام وطلبات الدمج.
- كل مهمة لها مسؤول واحد ونطاق ملفات واضح.
- ناقشوا الموضوع في Discord، ثم سجّلوا القرار والنتيجة في GitHub Issue أو Pull Request.
- لا يغيّر أي طرف قاعدة بيانات الآخر أو كلمات مروره أو منافذ تشغيله.
- شاركوا ملخصات المحادثات ذات الصلة فقط بعد إزالة الأسرار والبيانات الشخصية.
- رفع الكود المعتمد لدى سيف خطوة منفصلة بعد تحديد المستودع المرجعي؛ لا تستبدلوه بنسخة أخرى.
