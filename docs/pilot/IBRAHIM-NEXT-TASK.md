# أول مهمة لإبراهيم بعد تسليم الكود

الحزمة الأساسية أصبحت موجودة؛ لا تعِد بناء bootstrap من الصفر. اقرأ START-HERE-AR.md وSTATUS-AR.md وVERIFICATION.md.

1. راجع PR تسليم سيف، وجرّب فرعه على جهاز Windows بقاعدة وحاويات ومنفذ خاصين. لا تستخدم ديمو Windows القديم أو قاعدة سيف.
2. وثّق Git commit والمصدر والصورة، وأن الإضافة تثبت والمنيو يفتح وsmoke_customer ينجح. سجّل أي عائق Windows بوضوح. لا تنشر أسرار .env أو سجل يحملها.
3. إن وافقت المراجعة يُدمج PR وفق اتفاق الفريق، ثم افتح `ibrahim/pilot-ops` من main المحدث. عند بدء العمل قبل الدمج اجعل فرعك مبنياً على فرع التسليم واذكر الاعتماد في PR.
4. طوّر تحت pilot_ops/ وpilot_tests/ وdocs/pilot/: نسخ قاعدة + filestore معاً، واستعادة إلى قاعدة/volumes جديدة فقط، واختبار فعلي يثبت الاستعادة. لا حذف قاعدة ولا down -v ولا استبدال بيانات قائمة.
5. أضف اختبار ظهور الطلب في واجهة POS ثم اختبارات الدفع التجريبي/الإيصال/المرتجع عند الإمكان. لا تدّعِ طباعة أو iPad بلا جهاز فعلي. لا تنفذ دفعات حقيقية.

لا تغيّر custom_addons/ أو المصدر أو التصميم في هذه المهمة؛ خلل فيها يوثّق مع دليل لإصلاح مستقل. النتيجة المطلوبة PR بأوامر تشغيل ودليل نجاح/فشل/تعذر، وليس استهلاك التوكنز. ربط الآيباد والشبكة والطابعة يحتاج معلومات الجهاز واختباراً ميدانياً منفصلاً.
