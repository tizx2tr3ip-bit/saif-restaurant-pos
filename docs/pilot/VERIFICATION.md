# التحقق من حزمة التسليم

16 أكتوبر 2026، macOS arm64 مع Docker Linux containers.

- جلب مصدر رسمي نظيف عند commit المثبت، وتسجيله Git submodule دون نسخ تاريخ أودو إلى المستودع.
- تطابق بصمات ملفات الإضافات الـ16 مع نسخة سيف المحلية؛ لم تتغير وظائفها في النقل.
- فحص تركيب Python وXML وJavaScript وgit diff --check.
- رفض الكتابة فوق إعدادات init موجودة، وحصر اسم مشروع التشغيل وقاعدة الديمو.
- فحص تجاهل .env و.runtime/odoo.conf ومراجعة ملفات التسليم بحثاً عن أسرار ظاهرة؛ لا قاعدة أو filestore أو مفاتيح طاولات من نسخة سيف ضمن التسليم.
- تجربة إنشاء قاعدة فارغة جديدة تماماً وتثبيت الوحدات، ثم تهيئة صنفين وطاولات وجلسة: نجحت بعد تصحيح استخدام API إعدادات Odoo20 وإعداد HTTP الداخلي وانتظار الصحة.
- اختبار من منفذ المضيف: catalog وquote وطلب سيارة وإعادة نفس الطلب وطلب طاولة: نجح. طلبا draft غير مدفوعين محفوظان في بيئة التحقق فقط. الدليل VERIFICATION.json.
- أُوقفت حاويات التحقق مع الاحتفاظ ببياناتها؛ نسخة سيف على8071 وقاعدتها لم تُعدّلا.

Windows لم يُختبر هنا. طلبات API ليست إثبات ظهور الطلب في POS بصرياً أو وصوله لطابعة/شاشة مطبخ. الدفع والمرتجع واللغة والطباعة الميدانية ضمن اختبارات لاحقة. الحزمة تطوير وليست وصفة نشر إنتاجي.
